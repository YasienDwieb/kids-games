# iOS App Store screenshots

Kids Zone is **landscape-only**. One folder per App Store locale, flat:

```
en-US/  ar-SA/
  iphone-01.png … iphone-10.png   # 2796 x 1290 → iPhone 6.9" slot
  ipad-01.png   … ipad-08.png     # 2752 x 2064 → iPad 13" slot
```

`deliver` picks each image's device slot from its pixel size, and orders by file
name. Apple accepts 2–10 per slot; the 13" iPad set is required because the app
declares `supportsTablet: true`. RGB only (no alpha), and never put "framed" in a
file name (deliver then skips the other files).

## Refreshing

Generated by the store screenshot pipeline (`.claude/skills/store-screenshots`):
`screenshots/render.js` writes `screenshots/out/store/<en|ar>/ios-{phone,ipad}/`,
and that skill's copy step lands them here.

## Uploading

```bash
fastlane ios screenshots                     # the version that's "Prepare for Submission"
fastlane ios screenshots app_version:1.3.0   # or name it
```

It replaces that version's screenshots in both locales and touches nothing else:
no text, binary or submission. It uses the ASC API key from `eas.json`.
Check the version page in App Store Connect afterwards.
